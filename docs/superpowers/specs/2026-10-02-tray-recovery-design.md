# Tray recovery and optional usage window

Approved in chat on October 2, 2026.

Closing the widget hides it without stopping usage refresh. A tray icon remains available. Double-click and Show widget restore and activate it. Both widget and tray context menus offer Refresh Immediately and Exit. Exit closes the window, disposes timers/client and tray resources, and shuts down the app. Preserve the existing startup toggle and settings.

The five-hour row and its reset text are collapsed when the successful response has no five-hour window. A reported zero remaining is still visible. Refresh failures retain the previous snapshot and mark it stale. The current account returns weekly data with secondary=null; do not invent a five-hour window or borrow a model-specific quota.

Build and run the updated executable, replace any old widget process, and set the user's Windows startup entry to this executable. Verify the registered path and running process match. Tests cover absent/present/zero quota transitions, stale data, and close/restore/exit lifecycle. Use an original SVG icon and convert it to ICO for Windows tray and executable resources.
